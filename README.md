# Chronicle.Plugin.IMDb

Metadata provider plugin for **IMDb**.

## Design Document

Full design documentation:
[docs/plugins/PLUGIN_IMDB.md](https://github.com/thegoddamnbeckster/Chronicle/blob/develop/docs/plugins/PLUGIN_IMDB.md)

## Supported Media Types

`movie`, `tv`

## Quick Start

1. `dotnet build`
2. Copy `Chronicle.Plugin.IMDb.dll` to your Chronicle `plugins/active/` directory
3. Restart Chronicle
4. Navigate to **Settings -> Plugins -> IMDb**
5. Configure required settings (see design doc)
